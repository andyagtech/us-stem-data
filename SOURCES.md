# Sources

Every dataset this project draws on, grouped by who publishes it. **70 datasets**, of which **61** come from an outside source with a retrieval URL and **9** are built here from the others.

Generated by `scripts/build_sources_page.py` from `pipeline/datasets.py`. Do not edit by hand — it will be overwritten, and the catalogue is what the consistency checks read.

A source URL is the page a reader goes to, not always a direct file link: several agencies serve their tables through a search interface, and two (travel.state.gov, and the DOL enforcement portal) refuse automated requests entirely, so those files were retrieved by hand.

## How to check this

```
python3 scripts/check_consistency.py
```

Two of the seventeen checks bear on this page: *every catalog path exists* and *every external dataset cites a source URL*. A dataset added without a source fails the build rather than appearing here unattributed.
