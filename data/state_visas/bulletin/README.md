# Visa Bulletin — where to put the files

Save each month's bulletin here as `YYYY-MM.html` (or `.pdf`), e.g.
`2026-02.html`, `2015-06.html`.

Source: https://travel.state.gov/content/travel/en/legal/visa-law0/visa-bulletin.html

## What is wanted

The **Final Action Dates for Employment-Based Preference Cases** table, and
the **Dates for Filing** table if the page carries one. The India column of
the EB-2 and EB-3 rows is the figure the project needs: the priority date
being acted on now, against the bulletin's own month, gives the wait in years.

Two or three widely spaced months are worth more than a run of consecutive
ones — one recent, one around 2015, one around 2010 shows whether the queue is
lengthening.

`travel.state.gov` returns 403 to automated requests from this machine,
including a headless browser, so these are downloaded by hand.
