# PhD Student Directory Audit

Last updated: 2026-04-01

## Summary

Searched 60+ universities across CS, ECE, Physics, and Chemistry departments for public-facing PhD/graduate student directory pages.

| Metric | Count |
|---|---|
| Universities with student directory links | 42/107 |
| Total student directory URLs found | 137 |
| Universities where NO public directory exists | ~65 |

## Directory Types Found

- **PhD-only**: Lists only doctoral students (e.g., Penn State CSE, NC State CS, Northwestern CS, NJIT CS)
- **All grad students**: PhD + Master's combined (e.g., Purdue CS, UMD CS, Stony Brook CS, UC Irvine)
- **All people (filterable)**: Combined faculty/staff/students with filter options (e.g., Harvard SEAS, Georgia Tech, Yale)
- **Graduate employees**: Lists students with teaching/research appointments only (e.g., U Oregon CS)

## Notes

1. Many universities are moving to centralized directory systems that require JavaScript rendering
2. Some directories are behind authentication or only accessible on campus networks
3. The distinction between "PhD students" and "graduate students" varies — some departments include Master's students, post-docs, or visiting scholars
4. Directory URLs may change as universities redesign their websites
5. Some departments use external tools (e.g., university-wide directory systems) rather than department-specific pages
